# دليل المستخدم — النسخة التجريبية (عربي)

**الإصدار:** تجريبي 1.0  
**الجمهور:** العملاء المحتملون لتقييم المنصة  
**الشركة في العرض:** شركة فراتيلانزا للتطوير العقاري

---

## 1. مقدمة

فراتيلانزا منصة متكاملة لمطوري العقارات. تربط دورة العمل الكاملة في مكان واحد:

- **المبيعات:** عملاء محتملون → عملاء → حجوزات → عقود  
- **التحصيل:** أقساط ومدفوعات  
- **التشغيل:** مشاريع، مقاولات، مشتريات، مخازن  
- **الدعم:** متابعات، خدمة عملاء، موارد بشرية، مالية، تقارير  

يوضح هذا الدليل بيئة **العرض التجريبي** خطوة بخطوة لاستكشاف الميزات الرئيسية دون تدريب مسبق.

> **النسخة الإنجليزية:** [DEMO-USER-MANUAL.md](./DEMO-USER-MANUAL.md)

## 2. الدخول إلى العرض التجريبي

| البند | القيمة |
|-------|--------|
| **صفحة الدخول** | افتح رابط العرض (مثال: `http://your-server:9000/login`) |
| **البريد الإلكتروني** | `admin@demo.fratelanza.com` |
| **كلمة المرور** | `Demo123456` |
| **الدور** | مدير الشركة (وصول كامل لوحدات الشركة) |

### أول تسجيل دخول

1. أدخل البريد وكلمة المرور ثم اضغط **تسجيل الدخول**.
2. ستصل إلى **لوحة التحكم** مع بطاقات المؤشرات (المبيعات، التحصيل، الوحدات المتاحة، العملاء المحتملون).
3. استخدم **مبدّل اللغة** (أعلى الشاشة) للتبديل بين **العربية** و**الإنجليزية**.

### إذا كانت الجداول فارغة

1. اذهب إلى **لوحة التحكم**.
2. اضغط **تحميل بيانات تجريبية** (أعلى اليمين).
3. انتظر رسالة التأكيد، ثم افتح أي وحدة من القائمة الجانبية.

## 3. تخطيط الشاشة

```
┌─────────────────────────────────────────────────────────────┐
│  الشعار   بحث عام   اللغة   الإشعارات   الملف الشخصي        │
├──────────────┬──────────────────────────────────────────────┤
│              │                                              │
│  القائمة     │              منطقة المحتوى الرئيسية           │
│  الجانبية    │   عنوان الصفحة + أزرار إضافة / تصدير         │
│              │   جداول، رسوم بيانية، نماذج، كانبان           │
│              │                                              │
└──────────────┴──────────────────────────────────────────────┘
```

| المنطقة | الوظيفة |
|---------|---------|
| **القائمة الجانبية** | التنقل بين الوحدات |
| **البحث العام** | البحث عن عملاء، عملاء محتملين، عقود، وحدات، مشاريع |
| **إجراءات سريعة** | إضافة عميل، جدولة مكالمة، إضافة مستخدم |
| **رأس الصفحة** | عنوان الوحدة + الإجراءات الرئيسية |
| **صفوف الجدول** | **تعديل** و**حذف** في معظم القوائم |

### الأزرار الشائعة

| الزر | المعنى |
|------|--------|
| **إضافة** (+) | إنشاء سجل جديد |
| **تعديل** | تغيير سجل موجود |
| **حذف** | إزالة أو إيقاف (مع تأكيد) |
| **تصدير Excel** | تحميل الجدول الحالي |

```mermaid
flowchart RL

    B --> C[مشاريع / وحدات]
    C --> D[حجز]
    D --> E[اعتماد]
```

| الخطوة | الوحدة | ماذا تفعل |

| 5 | **العقود** | حوّل الحجز المعتمد لعقد |
| 6 | **التحصيل** | سجّل دفعة على قسط مستحق |
| 7 | **المالية** | المركز المالي وقائمة الدخل |
| 8 | **المتابعات** | جدولة مكالمة؛ إتمامها مع النتيجة |
| 9 | **التقارير** | تصدير تقارير Excel |

## 5. دليل الوحدات

### 5.1 لوحة التحكم

- بطاقات المؤشرات: إجمالي المبيعات، التحصيل، الوحدات المتاحة، العملاء النشطون  
- **مركز الإجراءات:** متابعات، مبالغ متأخرة، موارد بشرية  
- **تحميل بيانات تجريبية:** يملأ الوسطاء والمخازن والحجوزات والمقاولات  

---

### 5.2 العملاء

| الإجراء | الخطوات |
|---------|---------|
| **إضافة عميل** | **إضافة عميل** → الاسم عربي/إنجليزي، الجوال، المدينة → حفظ |
| **استيراد جماعي** | **استيراد جماعي** → رفع ملف Excel |
| **جدولة مكالمة** | من صف العميل → تذكير في المتابعات |

**بيانات تجريبية:** أحمد محمد — `+201012345678`

---

### 5.3 العملاء المحتملون

**عرض كانبان:** أعمدة = مراحل المبيعات (جديد → تم التواصل → … → توقيع عقد / خسارة)

| الإجراء | الخطوات |
|---------|---------|
| **إضافة** | **إضافة عميل محتمل** → الاسم، الجوال، المصدر، المشروع |
| **تغيير المرحلة** | القائمة المنسدلة على البطاقة |
| **تعديل / حذف** | أيقونة القلم أو سلة المهملات |
| **جدولة مكالمة** | على البطاقة → تظهر في المتابعات |

**بيانات تجريبية:** سارة علي — فيسبوك، مهتمة

---

### 5.4 المتابعات

- قائمة اليوم والمتأخر  
- لوحة التفاصيل للتذكير المحدد  
- **جدولة مكالمة** مرتبطة بعميل أو عميل محتمل  
- **إتمام المكالمة** مع تسجيل النتيجة  
- روابط **واتساب** و**اتصال** مباشرة  

---

### 5.5 المشاريع والوحدات

#### لوحة الوحدات

| اللون | الحالة | المعنى |
|-------|--------|--------|
| أخضر | متاح | جاهز للبيع |
| كهرماني | محجوز | محجوز مؤقتاً |
| أزرق | متعاقد | تحت عقد فعّال |

| الإجراء | الخطوات |
|---------|---------|
| **حجز وحدة** | اضغط بطاقة **متاحة** → يفتح نموذج الحجز |
| **إضافة مشروع** | **إضافة مشروع** |
| **إضافة وحدة** | **إضافة وحدة** → الدور، الكود، المساحة، السعر |

**مشروع تجريبي:** فراتيلانزا ريزيدنس (FR-001) — وحدات A1-01 إلى A1-05

---

### 5.6 الحجوزات

| الإجراء | الخطوات |
|---------|---------|
| **إضافة** | عميل + وحدة + عربون + تواريخ |
| **اعتماد** | أيقونة ✓ عندما الحالة *بانتظار الاعتماد* |
| **تحويل لعقد** | أيقونة المستند عندما الحالة *معتمد* |
| **تعديل / حذف** | من صف الجدول |

**قاعدة:** إنشاء حجز **يقفل** الوحدة لمنع البيع مرتين.

**تجريبي:** RES-DEMO-001 — وحدة A1-02

---

### 5.7 العقود

| الإجراء | الخطوات |
|---------|---------|
| **إضافة عقد** | عميل + وحدة + السعر الإجمالي + التاريخ |
| **من حجز** | اعتماد الحجز → **تحويل لعقد** |
| **التحصيل** | أيقونة البطاقة → الانتقال للتحصيل |

**تلقائي:** العقد الجديد ينشئ **خطة سداد** و**أقساط** في التحصيل.

**تجريبي:** CNT-DEMO-001 — أحمد محمد، A1-01، 2,500,000 جنيه

---

### 5.8 التحصيل

يعرض الأقساط مع: رقم العقد، اسم العميل، كود الوحدة، المستحق، المدفوع، المتبقي، الحالة.

| الإجراء | الخطوات |
|---------|---------|
| **تسجيل دفعة** | أيقونة البطاقة على قسط غير مدفوع → المبلغ والتاريخ والطريقة |

---

### 5.9 الوسطاء

إضافة وتعديل وحذف الوسطاء مع نسبة العمولة.

**تجريبي:** محمد الوسيط — عمولة 3%

---

### 5.10 المالية

تبويبات: نظرة عامة، ميزان مراجعة، قائمة دخل، مركز نقدي، قيود، دليل حسابات.

---

### 5.11 المقاولات

مراحل مرتبطة بالمشروع مع نسبة الإنجاز والتكاليف.

**تجريبي:** الهيكل الخرساني (65%)، التشطيبات (20%)

---

### 5.12 المشتريات

إدارة **الموردين**: إضافة، تعديل، إيقاف.

---

### 5.13 المخازن

| التبويب | المحتوى |
|---------|---------|
| **المخزن** | مواقع التخزين |
| **أصناف المخزون** | أكواد، كميات، تنبيه انخفاض المخزون |

---

### 5.14 الموارد البشرية

موظفون، رواتب، إجازات، حضور — مع **توليد كشف رواتب** شهري.

---

### 5.15 التقارير

جداول قابلة للفرز والتصدير: مخزون، مبيعات، مالية، موارد بشرية.

## 6. سيناريو مبيعات كامل (تطبيق عملي)

### السيناريو: مشتري جديد يحجز شقة A1-03

1. **عملاء محتملون** → **إضافة** — عمر حسن، جوال، مصدر: زيارة مباشرة  
2. **عملاء** → **إضافة عميل** (نفس الشخص)  
3. **مشاريع** → **لوحة الوحدات** → اضغط **A1-03** (خضراء)  
4. نموذج الحجز: العميل، عربون 100,000، انتهاء بعد 14 يومًا → **حفظ**  
5. **حجوزات** → **اعتماد** (✓)  
6. **تحويل لعقد** — السعر 2,500,000 → **حفظ**  
7. **تحصيل** → **تسجيل دفعة** على القسط الأول  
8. **لوحة التحكم** → تحقق من تحديث المؤشرات
